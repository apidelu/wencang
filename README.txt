文藏 · 公众号文章转 PDF — Windows 本地版 1.3

更新使用
1. 关闭旧版 Start.cmd 的启动窗口（或在窗口内按 Ctrl+C）。
2. 将新版 ZIP 完整解压到新文件夹，运行其中的 Start.cmd。
3. 浏览器打开 http://127.0.0.1:8765/。若仍显示旧界面，按 Ctrl+F5 刷新。
4. 左下角应显示 LOCAL 1.3。重新导入原来的 articles.json 即可。

首次准备
安装 Node.js 22 或更新版本：https://nodejs.org/
电脑需要已安装 Microsoft Edge 或 Google Chrome，程序会自动查找它们来生成 PDF。
不需要 npm install，不需要手动打开浏览器的打印窗口来完成批量导出。
本压缩包不包含或自动安装 Node.js、Edge、Chrome。

articles.json 如何制作
1. 可通过“取阅” https://feed.zoro.build/ 获取目标公众号的文章清单，保留标题、完整原文链接和发布日期；也可从微信文章页面自行整理。
2. 取阅是独立第三方工具，具体操作和可导出格式以其当前页面为准。已有 JSON 若符合本项目格式，可直接导入；其他表格或文本需要先整理，不能只改文件后缀。
3. 复制 docs/articles.example.json，用记事本替换示例公众号名称、标题、日期和链接。示例链接是占位符，必须换成真实微信文章链接。
4. articles 数组中每篇填写 title、url、publishedAt；url 必填并保留完整参数，publishedAt 使用文章发布日期 YYYY-MM-DD，未知日期留空，不要填写导出当天的日期。
5. 多篇文章增加相同结构的对象，对象之间用英文逗号分隔，最后一项后不要加逗号。
6. 记事本“另存为”：文件名 articles.json，保存类型“所有文件”，编码 UTF-8，避免变成 articles.json.txt。
7. 每批最多 100 条，文件不超过 2 MB；超过时拆成多个完整 JSON 文件。
完整模板、字段解释和辅助整理提示词见 README.md 的“articles.json 如何制作”。
JSON 是文章清单，不包含完整正文也能使用；文藏按其中的链接联网提取。当前不会仅凭公众号名称自动列出全部历史文章。

批量分别导出（每篇一个 PDF）
1. 点击“JSON 批量”，选择自己的 articles.json。
2. 勾选文章，点击“提取所选正文”。JSON 是清单，摘要不代替完整正文。
3. 点击“分别导出 PDF”。程序先分批加载图片，再逐篇生成 PDF。
4. 多篇文章打包为一个 ZIP 下载，ZIP 内每篇都是独立 PDF；不会合并文章。
5. 文件名为“YYYY-MM-DD_文章标题.pdf”，日期取文章发布日期；缺失时标“日期不详”。
6. 重名文件自动加 (2)、(3)；Windows 不支持的文件名字符会替换为下划线。
7. 每行的“下载 PDF”可单独下载该篇。下载没有自动开始时，点击页面上的下载链接。
8. 可随时停止，已生成的文件仍会打包下载。未完成项需要再次选择导出。
清单及正文暂存在当前页面，刷新或关闭后需要重新导入。

图片处理
图片最多分四路读取，每张从开始读取时单独计时，成功图片在本机服务内暂存。
导出前将成功图片嵌入文档，生成 PDF 时无需再次向微信下载。
若仍有图片失败，页面显示具体原因；可取消导出后重试。
选择继续时，PDF 会在缺图位置显示说明。关闭“保留文章图片”可导出纯文字。
提取文章和读取网络图片需要联网；微信返回验证页或限制访问时不会绕过验证。

单篇与直接打开 HTML
通过 Start.cmd 启动后，也可粘贴单篇链接、粘贴正文或导入 HTML/TXT。
“导出当前预览 PDF”使用浏览器打印窗口，选择“另存为 PDF”；建议关闭浏览器页眉页脚。
双击 index.html 无需 Node.js，可粘贴正文、导入网页文件和打印单篇。
直接打开 HTML 不能从 JSON 清单提取全文，也不能使用后台批量分别生成 PDF。

文件说明
index.html：已内嵌界面程序与样式。
server.mjs：本机文章、图片和 PDF 服务，仅监听 127.0.0.1。
pdf-export.mjs：调用本机 Edge / Chrome 生成独立 PDF，不要删除。
Start.cmd：Windows 启动入口，使用期间保持该窗口打开。
source：可修改的界面源码，日常使用无需打开。
ThirdPartyNotices.txt：组件许可。

故障处理
- 找不到 Node.js：安装后关闭旧窗口，重新运行 Start.cmd。
- 找不到 Edge/Chrome：确认已安装其中一种浏览器，再重启文藏。
- 8765 端口占用：关闭之前的文藏启动窗口，不要随意关闭不认识的系统进程。
- 仍提示旧版的“67 张图片暂时无法加载”：确认解压的是新版，关闭旧服务后重启，浏览器 Ctrl+F5。
- 图片仍失败：查看新版显示的 HTTP、网络、超时或格式提示。
- PDF 生成失败：确认 Edge/Chrome 可以正常打开；单位电脑的管理策略也可能限制后台转换。

草稿与隐私
草稿保存在当前浏览器，最多 8 篇。清理浏览器数据会删除草稿。
本地版不依赖在线 Site，不需要登录 ChatGPT，不向局域网提供服务。
转换使用独立的临时浏览器目录，不读取个人浏览器登录信息；完成后清理临时文件。

测试说明
图片队列、67 张图片的打印加载、文件日期命名、ZIP 格式、接口和转换参数已在开发环境检查。
当前环境不是 Windows，未完成 Windows Edge/Chrome 后台生成 PDF 的实机验证。
如需自行修改界面，在 source 目录使用 Node.js 22.13+，执行 npm install 和 npm run build。
普通使用不需要上述开发步骤。
