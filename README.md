# 文藏 · 公众号文章转 PDF

用于个人阅读归档的本地应用。导入公众号文章清单，提取全文和图片，按文章发布日期分别导出 PDF。

## 功能

- 导入 `articles.json`，识别标题、发布日期和链接；每批最多 100 条。
- 勾选逐篇提取，显示状态，支持停止、继续和失败重试。
- 每篇独立 PDF，多篇打包 ZIP；文件名为 `YYYY-MM-DD_文章标题.pdf`。
- 日期缺失标记“日期不详”，重名自动加序号。
- 图片分批读取、去重、缓存并嵌入文档，失败显示原因。
- 支持单篇链接、粘贴正文、HTML/TXT 导入、排版预览和浏览器草稿。

## Windows 使用

1. 下载整个项目并完整解压。
2. 安装 [Node.js](https://nodejs.org/) 22 或以上版本，电脑需已安装 Edge 或 Chrome。
3. 双击 `Start.cmd`，保持启动窗口打开。
4. 浏览器打开 `http://127.0.0.1:8765/`。
5. 选择“JSON 批量”→导入清单→提取正文→“分别导出 PDF”。

普通使用不需要 `npm install`，界面已包含在根目录 `index.html` 中。

清单结构见 [示例文件](docs/articles.example.json)，其中链接为占位符，请替换为自己的文章链接。JSON 摘要不代替全文。

直接双击 `index.html` 可使用粘贴、文件导入和单篇打印；链接提取和自动批量 PDF 需要本地服务。详细说明见 [README.txt](README.txt)。

## articles.json 如何制作

批量导出前，需要先准备文章清单。可使用 [取阅](https://feed.zoro.build/) 获取目标公众号的文章信息，再整理为文藏支持的 JSON。取阅是独立的第三方工具；本项目最初适配的清单由使用者从取阅获取，文藏负责后续正文提取和 PDF 导出。

### 1. 获取文章信息

在取阅中取得需要归档的文章清单，保留每篇文章的**标题、原文链接、发布日期**。具体操作和可导出格式以取阅当前页面为准。

- 已有 JSON：先与下方格式对照；字段一致即可直接导入。
- 已有表格或文本清单：按下方模板整理。也可以直接从微信文章页面复制这些信息，不必限定清单来源。

仅把 Excel、TXT 文件的后缀改为 `.json` 不会完成格式转换。不同工具的 JSON 字段可能不同，需要按模板对应填写。

### 2. 保存为 JSON 文件

复制项目中的 [docs/articles.example.json](docs/articles.example.json)，用记事本打开，替换示例内容。以下是一篇文章的最小实用模板：

```json
{
  "account": { "name": "公众号名称" },
  "articles": [
    {
      "title": "文章标题",
      "publishedAt": "2026-11-03",
      "url": "https://mp.weixin.qq.com/s/REPLACE_WITH_ARTICLE_ID"
    }
  ]
}
```

**示例链接是占位符，必须替换为真实的微信文章链接。** 多篇文章就在 `articles` 中增加相同结构的对象，对象之间用英文逗号分隔，最后一项后不要加逗号。

| 字段 | 填写方式 |
| --- | --- |
| `url` | 必填。保留完整的微信文章链接；长链接中的参数也要保留。 |
| `title` | 建议填写实际标题，用于列表和导出文件名。 |
| `publishedAt` | 建议填文章发布日期，如 `2026-11-03`；不是制作清单的日期。不知道可留空，不能编造。也支持 `publishedAtUnix` 秒级时间戳。 |
| `account.name` | 可选，填写公众号名称。 |

在 Windows 记事本中选择“另存为”：文件名填 `articles.json`，保存类型选“所有文件”，编码选“UTF-8”，避免保存成 `articles.json.txt`。

不熟悉 JSON 时，可把已有清单交给 AI，使用这段提示词整理，并核对结果：

> 请把下面的文章清单整理为 JSON，顶层使用 account.name 和 articles 数组；每篇使用 title、url、publishedAt。保留我提供的完整原文链接，日期统一为 YYYY-MM-DD；缺失的标题或日期留空，不编造信息，没有链接的文章单独列出，不加入 articles。只用我提供的清单，不自行补充文章。最后给我可保存为 articles.json 的纯 JSON 内容。

### 3. 导入文藏

启动文藏，选择“JSON 批量”→导入 `articles.json`→勾选文章→“提取所选正文”→“分别导出 PDF”。

每批最多 **100 条**，文件不超过 **2 MB**；超过时拆成多个独立、完整的 JSON 文件。清单只需要文章信息，不需要包含正文或图片；文藏会根据链接联网读取。摘要不能代替全文，文藏目前也不会仅凭公众号名称自动生成全部历史文章清单。

## GitHub Pages

GitHub Pages 提供静态网页托管。本项目需要 Node.js 读取文章和图片，并调用本机 Edge / Chrome 生成 PDF。因此 GitHub 仓库用于分发源码和本地应用；GitHub Pages 无法独立提供完整功能。

## 开发与测试

开发使用 Node.js 22.13 或以上版本。

```sh
# 用现成界面启动，无需安装前端依赖
npm start

# 运行测试，无需安装前端依赖
npm test

# 修改前端后重新生成根目录 index.html
npm --prefix source install
npm run build
```

Python 可选：已安装时执行独立 ZIP 兼容性测试，否则跳过该项。普通使用无需 Python。服务端仅使用 Node.js 内置模块。

## 数据和边界

本地服务只监听 `127.0.0.1`，不需要微信或 ChatGPT 登录。读取公众号内容需要联网；遇到微信验证、限制或无法访问会报错，不会绕过验证。音视频和复杂互动组件不保留。

批量清单和正文暂存在当前页面，刷新需重新导入。草稿在当前浏览器中，清理浏览器数据会删除草稿。PDF 转换使用独立临时浏览器目录，不读取个人浏览器登录状态。

仓库仅含程序和合成测试数据，不包含使用者的文章清单、归档或凭据。
